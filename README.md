## 🌟 Tentang Portofolio

Repositori resmi **Personal Portfolio Website** milik **Angga Wiranata**. Portofolio ini mengombinasikan desain antarmuka *Cyberpunk Glassmorphism*, kecepatan muat instan, dan fitur khusus **Merdeka Mode (Edisi HUT RI ke-81)** dengan efek konfeti interaktif Canvas, audio lagu kebangsaan, ornamen budaya nusantara, serta penghitung waktu mundur kemerdekaan.

## 🛠️ Instalasi & Menjalankan Lokal

```bash
# 1. Clone repository
git clone https://github.com/kyraaa-dev/portofolio-angga.git

# 2. Masuk ke direktori
cd portofolio-angga

# 3. Install dependencies
composer install
npm install

# 4. Konfigurasi environment
cp .env.example .env
php artisan key:generate

# 5. Jalankan migrasi & database seeder
php artisan migrate --seed

# 6. Jalankan server lokal
php artisan serve
```
