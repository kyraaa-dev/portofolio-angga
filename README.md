## 🌟 Tentang Portofolio

Selamat datang di repositori resmi **Personal Portfolio Website** milik **Angga Wiranata**. Portofolio ini dirancang dengan estetika modern, *cyberpunk-minimalist glassmorphism*, performa tinggi, serta dilengkapi fitur khusus **Merdeka Mode (Edisi HUT RI ke-81)** dengan efek konfeti interaktif, musik nasional, ornamen batik, dan hitung mundur kemerdekaan.

## 🇮🇩 Fitur Spesial: Merdeka Mode (HUT RI ke-81)

Portofolio ini mengusung perayaan kemerdekaan Indonesia dengan fitur-fitur eksklusif:

- 🎊 **Dynamic Confetti Cannon**: Efek taburan konfeti Merah-Putih real-time berbasis HTML5 Canvas.
- ⏳ **Countdown Timer HUT RI 81**: Penghitung mundur otomatis menuju 17 Agustus 2026.
- 🎵 **Audio Ambience**: Pemutar lagu kebangsaan interaktif dengan kontrol *mute/unmute*.
- 🛡️ **Garuda Pancasila Watermark**: Ornamen lambang negara dengan estetika halus di latar belakang.
- 🔴⚪ **Batik Border & Ribbon Accent**: Desain aksen bernuansa nusantara yang elegan.
- 🌐 **Bilingual Support (ID / EN)**: Dukungan dwibahasa untuk audiens lokal dan internasional.

## 🛠️ Instalasi & Menjalankan Lokal

```bash
# 1. Clone repository
git clone https://github.com/kyraaa-dev/portofolio-angga.git

# 2. Masuk ke direktori
cd portofolio-angga

# 3. Install dependensi Composer & Node
composer install
npm install

# 4. Konfigurasi environment
cp .env.example .env
php artisan key:generate

# 5. Jalankan migrasi & seeder
php artisan migrate --seed

# 6. Jalankan server lokal
php artisan serve
```

Buka browser Anda di `http://127.0.0.1:8000`.
