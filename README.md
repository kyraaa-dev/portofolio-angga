### [ PETUNJUK INSTALASI LOKAL ]

```bash
# 1. Clone repository
git clone https://github.com/kyraaa-dev/portofolio-angga.git
cd portofolio-angga

# 2. Install package
composer install && npm install

# 3. Setup environment
cp .env.example .env && php artisan key:generate
php artisan migrate --seed

# 4. Jalankan
php artisan serve
```
