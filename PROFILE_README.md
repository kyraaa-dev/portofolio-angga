## 👨‍💻 Tentang Saya (About Me)

Saya adalah seorang **Full Stack Web Developer** asal Indonesia yang berfokus pada pembangunan aplikasi web berkinerja tinggi, berarsitektur modern, dan memiliki pengalaman visual antarmuka yang memukau.

- 🔭 **Sedang Mengerjakan**: Ekosistem aplikasi manajemen cerdas, platform AI, dan sistem informasi institusi pemerintahan.
- 🌱 **Keahlian Utama**: **Laravel 11**, **React 18 / Next.js**, **TypeScript**, **Tailwind CSS**, dan **RESTful API Architecture**.
- 💡 **Filosofi Coding**: *Clean Code, Scalable Architecture, and Pixel-Perfect Visual Aesthetics.*
- 💬 **Tanya saya seputar**: Laravel, React, State Management, UI/UX Glassmorphism, Database Optimization.
- 🎯 **Tujuan**: Terus berkontribusi pada kemajuan transformasi digital Indonesia 🇮🇩.
